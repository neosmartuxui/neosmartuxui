# NeoSmartUXUI Foundry

This directory is the canonical source for the public NeoSmartUXUI Foundry.

The v0.1 page is intentionally an architecture bootstrap, not a fake gallery. Official flavor, vertical, Lab, Studio, Registry, and Agent surfaces will become live only as their shipping architecture exists.

Build with:

```bash
npm run build:foundry
```

Output is generated under `dist/foundry/` and is intended for the separate `neosmartuxui/neosmartuxui.github.io` deployment repository.
